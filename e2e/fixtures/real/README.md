# Empty desk reference

`empty-desk-reflection-overlay.png` is an owner-authorized empty-desk image
for this public repository. It contains no receipt, surrounding scanner controls
or status, account details or identifying text. The PNG has no ancillary metadata.

It is a pixel-preserving crop of a screenshot, not an original camera frame.
The yellow detection overlay is part of the screenshot and remains visible;
do not treat its edges as natural scene geometry or use it alone to calibrate
camera thresholds. The original report and surrounding receipt image are private
and must never be added here.

The fixture checks that this reflective background cannot pass as a receipt.
It also preserves visual evidence for the unresolved removal problem. Reliable
removal calibration still needs unannotated frame sequences showing both the
empty background and lifted/folded receipts; one empty frame cannot establish
safe duplicate prevention.

This permission applies only to this empty-desk crop. Receipt fixtures remain
synthetic.
